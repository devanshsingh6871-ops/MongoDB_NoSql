# MongoDB Installation & CRUD Operations – NoSQL Lab File

Lab file for the NoSQL 

## What's Inside
- **Practical 1 – MongoDB Installation:** installing MongoDB Community Server 7.0.14 on Windows, checking the service, and connecting with Compass and `mongosh`.
- **Practical 2 – CRUD Operations:** Create, Read, Update and Delete operations on an `employees` collection (22 documents, 19 after updates and deletes) using `insertMany()`, `find()`, `updateMany()`, `deleteMany()`, and operators like `$gt`, `$in`, `$set` and `$inc`.

## Tools Used
MongoDB Community Server, MongoDB Shell (`mongosh`), MongoDB Compass
